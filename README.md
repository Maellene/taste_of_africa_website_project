# taste_of_africa_website_project 

A multi-page website celebrating African food culture, built with HTML, CSS and JavaScript.

## Pages

- Home: hero video, featured dishes, regions, food trends
- Recipes: filter by region and save favorites
- Recipe pages: Jollof Rice (Nigeria), Tagine (Morocco), Isombe (Rwanda)
- Region pages: West Africa, North Africa, East Africa
- About Us: mission, history and map
- Contact: validated form

## Features

- Recipe filter by region
- Favorites saved with localStorage
- Ingredient servings scaler
- Dark and light mode
- Contact form validation with a personalised confirmation
- Newsletter signup in the footer
- Responsive layout

## How to run

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Technologies

HTML5, CSS3, JavaScript, Google Fonts
